# TopprismWiki Roadmap

TopprismWiki is currently a governed reference workflow. The roadmap separates
verified public behavior from planned product direction; it is not a release
schedule.

## Current

- Evidence and adapter contracts for approved source records
- Workspace snapshots, hashes, review packages and batch ledgers
- Review-gated atomic publication into a formal Markdown Vault
- Formal query, bounded context and typed REL graph projections
- Candidate relationship, conflict, status and diagnostic projections
- Read-only batch dashboard and synthetic end-to-end walkthrough
- Public privacy contract, capability matrix and stable error guidance

## Next

- Starter adapters for approved WeChat and document workflows
- Durable per-source and per-unit watermarks
- Stronger entity disambiguation and reverse-relationship validation
- Obsidian post-commit validation as an explicit deployment gate
- Reproducible labeled evaluation fixtures for admission and traceability
- More complete source-version and conflict-resolution workflows

## Later

- Entity and relationship evolution across version families
- Human-assisted conflict adjudication with auditable decisions
- Multi-agent knowledge collaboration with role-scoped publication
- Agent runtime integrations with bounded, evidence-aware context contracts

## Long-term direction

The long-term direction is an Enterprise Knowledge Operating Layer for
Agentic AI. That phrase describes the destination, not a capability currently
guaranteed by the public Runner.
