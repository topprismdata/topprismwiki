# 核心概念

TopprismWiki 将证据、正式知识和面向 Agent 的投影分开管理，避免一个有价值的线索在没有足够权威和证据时直接变成公司事实。

## 证据

证据是带有来源身份、内容哈希、时间、位置锚点和处理状态的来源观察。适配器输出的是证据输入，不等于正式知识。

## 正式知识

正式知识是通过来源、证据、实体和授权门禁的持久事实、决定、实体或类型化关系，由确定性提交器写入正式 Vault。

## 候选与冲突

候选关系、待裁决实体和互相矛盾的陈述保存在 Workspace 中，可以在明确标注的覆盖层或审阅包中展示，但不计入正式关系。

## Agent 上下文

Agent 上下文是对正式知识、证据锚点、时间和已知缺口的预算受控投影，不是所有原始文档的堆叠，也不会静默提升 Workspace 候选内容。

## 内置能力与部署能力

公开 Runner 实现治理参考路径。来源抽取、OCR、转写、实体裁决和生产验收可能需要部署方适配器或服务；完整边界以能力矩阵为准。
