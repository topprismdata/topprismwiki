# 评估说明

当前公开包验证的是治理工作流正确性，不宣称生产规模的知识准确率或 Agent 效果。

## 当前可复现检查

- 包校验发现并验证 8 个嵌套 Skill 模块；
- 单元测试覆盖明确授权、预览隔离、原子更新、回滚、查询、图谱、重试和诊断；
- 公开安全扫描检查凭证、私有路径和未脱敏来源示例；
- 合成闭环验证预览、审阅更新、验收、查询、图谱和看板。

## 治理指标

后续有标注数据后，应测量：

- 可追溯覆盖率；
- 正式准入精度；
- 重复检测精确率和召回率；
- 冲突检测和裁决审计完整性；
- 关系精度，且候选关系不得进入正式指标；
- 幂等性，即重复输入不产生新的正式变更；
- 回滚正确性，即提交失败后正式 Vault 不变。

## Agent 指标

稳定的标注知识集建立后，再评估上下文检索、证据引用完整性、答案支持度和任务级决策质量。在数据集、基线、环境和可重复流程进入仓库前，不报告幻觉下降、客户影响或生产可靠性。
