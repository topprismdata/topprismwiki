# 产品架构

TopprismWiki 对 Agent 展示一条受治理的知识生命周期，同时保留三个相互隔离的运行层。

~~~mermaid
flowchart LR
    S[已批准企业来源] --> A[来源适配器]
    A --> E[Evidence Workspace]
    E --> H[人工与策略审核]
    H --> P[确定性正式发布]
    P --> V[Formal Knowledge Vault]
    V --> X[上下文与查询投影]
    X --> G[Agent 应用]
    E -. 候选关系与冲突 .-> X
~~~

适配器负责将私有来源转换为证据记录，保留原件、稳定哈希和消息、页码、表格或视觉锚点。公开 Runner 不声称自己是微信导出器、Office 解析器或视觉服务。

Workspace 保存来源快照、证据包、审阅决策、冲突、候选关系、处理状态和可重建的看板产物。正式 Vault 只保存通过门禁的事实、规范实体、决定和类型化关系。

查询、上下文、图谱、状态和看板都是投影，不得绕过治理直接修改正式 Vault。
