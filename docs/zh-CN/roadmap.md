# TopprismWiki 路线图

当前项目是受治理的参考工作流，路线图用于区分已验证行为和产品方向，不代表发布日期。

## Current

- 已批准来源的证据与适配器合同
- Workspace 快照、哈希、审阅包和批次账本
- 审阅门禁和 Formal Vault 原子发布
- 正式查询、预算受控上下文和 REL 图谱
- 候选关系、冲突、状态和诊断投影
- 只读批次看板、隐私合同和能力矩阵

## Next

- 微信和文档适配器 starter kit
- 持久化逐来源、逐单元水位
- 更强的实体消歧和反向关系校验
- Obsidian 提交后验收门禁
- 正式准入和可追溯性的可重复评估数据

## Later

- 实体与关系跨版本演进
- 可审计的人工冲突裁决
- 带角色边界的多 Agent 知识协作
- 面向 Agent Runtime 的证据感知上下文合同

长期方向是面向 Agentic AI 的 Enterprise Knowledge Operating Layer；这不是当前公开 Runner 已保证的能力。
